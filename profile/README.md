# XEQM Labs

XEQM Labs is a privacy-preserving Proof-of-Stake network and developer platform. The network is operated by a global set of service nodes that earn XEQM for securing the chain. The developer platform exposes the network's privacy capabilities through a clean API, with XEQM serving as the access and usage token across staking, API consumption, and infrastructure rewards.
