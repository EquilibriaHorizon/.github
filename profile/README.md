# XEQM Labs - EXIOM Platform

**Privacy-preserving Layer 1. Pure Proof-of-Stake. Built for developers.**

XEQM Labs is a privacy-focused blockchain network and developer platform. The network is secured by service nodes that stake XEQM and earn rewards for participating in consensus. The developer platform exposes the network's privacy capabilities through a clean API, with XEQM serving as the access and usage token across staking, API consumption, and infrastructure rewards.
